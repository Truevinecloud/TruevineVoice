## Surface limitations

No controller consumes platform:billing:read, platform:billing:refund, platform:tenant:suspend, platform:technical:write or platform:admin:manage. Billing Admin therefore has no implemented authorized platform action/dashboard. Platform Owner has no role-management dashboard. Technical Admin is read-only. Customer reports summarize campaign records; they are not call-performance reports. Contact APIs exist, but apps/web/src/app has no contact dashboard page. Customer pages exist for campaigns, reports, billing, team, invitations and settings. Admin pages exist at / (operations), /support, /technical and /auditor; use the configured admin base path when opening them. The kit does not add missing product surfaces.

The previously audited production Owner admin@truevoice.com is historical context only, is not in this inventory, and is never queried or modified by this kit. No production snapshot was revalidated here.
