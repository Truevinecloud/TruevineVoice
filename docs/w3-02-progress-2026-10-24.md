### Runtime configuration and cost notes

For the adapter as currently merged, use a private Amazon S3 bucket with
`AUDIO_STORAGE_BUCKET` and `AUDIO_STORAGE_REGION`; grant the API runtime
least-privilege `s3:PutObject`, `s3:GetObject`, and `s3:DeleteObject` for only
that bucket/prefix, and use temporary role credentials from the AWS SDK chain.
The adapter sends `ServerSideEncryption: AES256`. Set `AUDIO_TTS_REGION` and
grant `polly:SynthesizeSpeech` to enable TTS. Do not put credentials in source,
progress documents, logs or repository environment files.

Amazon Polly Standard is the lowest-cost currently supported TTS choice:
AWS lists [$4 per million characters](https://aws.amazon.com/polly/pricing/)
outside its eligible free tier, versus $16 per million for Neural voices. AWS
lists up to 5 million Standard characters per month for the first 12 months
for eligible accounts. Amazon S3 Standard's published US East (N. Virginia)
rate is about $0.023/GB-month for the first 50 TB; request and outbound
transfer charges vary by region and usage. See [S3 pricing](https://aws.amazon.com/s3/pricing/).
These are estimates, not a bill forecast.

Cloudflare R2 Standard has a lower advertised baseline ($0.015/GB-month, 10 GB
free storage/month and no egress fee; see [R2 pricing](https://developers.cloudflare.com/r2/pricing/)),
but the [R2 S3 compatibility table](https://developers.cloudflare.com/r2/api/s3/api/)
marks `x-amz-server-side-encryption` unsupported. Since this release sends that
header on every upload, R2 is not a supported live target without a reviewed
adapter adjustment and provider integration test. Retain AWS S3 for live QA;
do not silently drop the encryption request to use a cheaper endpoint.

## Implementation notes

`@truevine/audio` defines file validation, the storage and TTS ports, an
S3-compatible storage adapter, and an Amazon Polly adapter. The API supports
tenant-authorized listing, browser recording/file uploads, TTS, short-lived
playback links and usage/audit records. Campaign creation/update can select an
audio asset only inside that campaign's organization; this records selection
but does not start call execution. The essential UI is `/app/audio` and the
audio selector on `/app/campaigns`.

The migration adds composite organization keys/FKs, idempotency operations and
an append-only usage trigger. Review its SQL and controlled migration run plan
before merge. Runtime bucket, AWS region and credential-chain configuration is
still absent, so live recording, playback and TTS remain blocked until platform
configuration exists. Production deployment remains unauthorized.
